# 🏰 Adventure Glory

A simple **Python CLI adventure game** where you explore a dungeon, collect items, get magical weapons, and fight a Giant Goblin boss.

## 🎮 Features

* 🧭 Dungeon exploration
* ⚔️ Boss fight system
* 🗡️ Random magical weapons
* 💎 Random treasures
* ❤️ HP & damage system
* 🎲 Random boss attacks
* 🔄 Replay system

## 🛠️ Built With

* Python
* `random` module

## 🚀 Run

```bash
python main.py
```
